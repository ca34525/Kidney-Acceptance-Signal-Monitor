# Decision 0017 — Broaden exploratory program prediction research

Accepted for planning under the user's request to focus on broad prediction experiments,
create a new branch and prepare the plan. See [Plan 0031](../plans/0031-program-prediction-sprint.md)
and [its specification](../specs/program-prediction-sprint-0031.md).

Execution update, September 9, 2026: the user subsequently authorized P0–P4, planned model
fits and historical evaluations, local research outputs, and up to two documented follow-up
rounds. This supersedes the planning-only boundary below; the study and application safeguards
remain in force.

The next research question covers five annual program outcomes and several simple/nonlinear
models. Acceptance is one target and one optional feature block, not the required explanation
for every outcome. The initial 20 experiments use shared code and a complete results ledger;
later exploratory changes receive versioned settings and a brief rationale, not a separate
approval or design document for every run.

Original V1 restrictions on extra model families and Plan 0024's proposed single-endpoint,
Ridge-only comparison describe those studies. They do not restrict this new user-selected
research direction. Original specifications, results and application behavior remain intact.
Plan 0024 remains deferred; this is not its functioning-transplant study under another name.

Choose a research candidate by prediction comparisons and a concrete review decision, following
Decision 0016's separation of model choice and demonstrated usefulness. Do not impose a new
arbitrary improvement or bias threshold and call it practical significance. Target selection
and model exploration are disclosed; no previously inspected year becomes fresh validation.

Use existing verified public source bindings, release-aware historical features, train-only
preprocessing and paired program comparisons. Extend only the source fields needed for the
question. Source gaps for an optional feature do not stop supported target/model experiments.
The source-vintage mapping is essential to avoid predicting outcomes already public at origin.

Specify ignored `data/research/program-prediction-0031/<run-id>/` for eventual research runs.
The current request delivers planning only. A future implementation follows the recorded
steps; this decision does not run a model, publish a ranking, release forecasts or change the
application. No simulation or patient/offer-level prediction is included.
