# Decision 0012 — Preserve the waiting-list screen and describe its actual counts

Accepted September 8, 2026 under the request to carry out Plan 0026.

The completed screen established frequency and list-growth magnitude, but did not establish
that every increase in transplant removals was large. Use a separate fixed descriptive contract
to show signed distributions and three mechanically selected program examples. Do not rerun its
continuation rule or reinterpret known outcomes as fresh validation.

Consume the original run through its pinned completion marker and payload hashes, reusing its
annual types and accounting functions. New calculations, trusted loading and reusable offline
HTML rendering live in `src/kasm/waiting_list_case_study/`. Write only to the separately authorized,
ignored `data/research/waiting-list-case-study-0026/` root. This keeps original evidence intact
and permits reproducible program briefs without workbook parsing or network access.

The [specification](../specs/waiting-list-case-study-0026.md) fixes the years, linear quartiles,
denominators, example-selection rule, claims and provenance. HTML and existing matplotlib support
the deliverables without a dependency or application change. Implementation follows failing
regressions first and ends after the analytical and presentation passes in
[Plan 0026](../plans/0026-waiting-list-case-study.md).
