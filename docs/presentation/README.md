# Presentation packages

The [current project walkthrough](data-walkthrough/README.md) is the maintained presentation.
Its corrected PowerPoint has 19 main slides and six reference slides. The present correction
preserves the approved design and sequence. A shorter 20-minute edition and the author's timed
rehearsal remain separate work.

These earlier packages are historical and superseded:

- [Original eight-slide V1 deck](kidney-acceptance-signal-monitor-interview.pptx) and its
  [historical guide](interview-rehearsal-guide.md). The binary retains an obsolete bias-rule
  narrative. That rule was a design mistake and no longer governs model selection.
- [Earlier V2 follow-up package](v2-followup/README.md), including its PowerPoint and HTML
  backup. It retains a known listing-period error in the July 2026 source discussion.
- [Walkthrough without the introduction](data-walkthrough/data-walkthrough.pptx) and its
  [historical provenance](data-walkthrough/package-provenance.json). It predates the current
  corrections.

Preserve these files to explain earlier work. Use the current package for a presentation.
No author rehearsal or presentation-machine inspection is implied by a document build.
